## DATA-015：主页自选股双口径历史行情

- 状态：Implemented
- 创建日期：2026-09-17
- 关联需求：DATA-004, DATA-005, DATA-014

验收：双口径真实数据与榜单逐只核对，日期、口径、交易所映射、失败保留旧文件有测试覆盖。

## DATA-014：股票池五年前复权历史行情

- 状态：Implemented
- 优先级：P1
- 创建日期：2026-09-17

为当前股票池逐股生成最近五个自然年的前复权日 OHLC 和原始成交量（手），复权截止日与榜单交易日一致。周 K 按周一至周五聚合开盘首值、最高最大值、最低最小值、收盘末值及成交量总和，末周可以未结束。输出实际起止日，历史不足五年不得补造；区间位置为 `(最新收盘 - 区间最低) / (区间最高 - 区间最低) × 100`，距高点为 `(最新收盘 / 区间最高 - 1) × 100`，相同高低值的位置为空。每股独立 JSON，失败保留旧文件并明确报错，浏览器拒绝与榜单日期不一致的旧历史。使用独立脚本接入现有每日构建，不改变榜单筛选和指标计算。

验收：真实股票池历史完整生成，周聚合、日历边界、无效值及日期一致性验证通过。

验证记录：2026-09-17，为 2026-09-16 榜单的 74 只股票生成真实历史，逐只核对最新收盘与榜单一致、日线日期升序、日周成交量汇总一致。17 项 Python 测试通过，覆盖五年日历边界、周 OHLC 聚合、末周、重复日期、无效值和原有股票池筛选。历史文件合计约 8.9 MB，逐股按需加载。

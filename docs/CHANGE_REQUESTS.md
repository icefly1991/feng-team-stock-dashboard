# Change Requests

> 当已确认需求需要改变时，不直接删除或覆盖旧需求。先建立 Change Request，记录原需求、新需求、原因和影响。

## 编号规则

- 正式变更：`CR-001`、`CR-002`、`CR-003`
- 示例或教学用途：使用显式标记，如 `CR-EXAMPLE`

## 状态说明

- `Draft`
- `Proposed`
- `Accepted`
- `Implemented`
- `Rejected`
- `Deferred`
- `Cancelled`

## CR-002：Growth 榜单改为 52 周内位置升序

- 状态：Implemented
- 提出日期：2026-08-25
- 决定日期：2026-08-25
- 提出人：项目用户
- 关联原需求：UI-009
- 关联新需求：UI-011
- 关联决策：ADR-004

### 原需求

Growth 股票池按 52 周内位置从高到低排列。

### 新需求

Growth 股票池按 52 周内位置从低到高排列，使位置越小的股票越靠前。

### 修改原因

原沟通中的“倒序”产生歧义，用户进一步明确需要低值在上。

### 影响分析

- 数据生成和前端展示排序同时改为升序
- 不改变 52 周位置公式、股票池筛选条件或数据源
- 搜索结果继续遵循同一排序

### 验收标准

- [x] 最小的 52 周位置排在第一行
- [x] 页面文案和方向箭头与升序一致

### 决定

接受，以用户明确说明的“位置越小越靠前”为准。

### 实施记录

2026-08-25 完成数据层、前端排序和页面提示调整。

## CR-001：新股票池只展示最新年度利润并增加主营业务

- 状态：Implemented
- 提出日期：2026-08-23
- 决定日期：2026-08-23
- 提出人：项目用户
- 关联原需求：UI-007, DATA-008
- 关联新需求：
- 关联决策：ADR-001, ADR-004

### 原需求

新股票池页面同时展示最近两个完整年度的归母净利润。

### 新需求

- 最近两个完整年度归母净利润均为正的筛选规则保持不变
- 页面只展示最新完整年度归母净利润
- 页面新增公司主营业务摘要，数据来自 Tushare `stock_company.main_business`
- 搜索同时匹配股票名称、代码和主营业务

### 修改原因

减少表格中重复的利润列，将空间用于帮助用户理解公司的主要业务。

### 影响分析

#### 数据影响

保留两年利润供筛选与追溯，新增 `main_business` 字段，不改变盈利筛选公式。

#### 前端影响

删除较早年度利润展示列，新增两行截断的主营业务列，完整内容通过悬停标题查看。

#### 后端或脚本影响

每次生成增加深交所和上交所各一次 `stock_company` 批量请求。

#### 部署影响

不改变部署入口，仅增加少量数据请求与 JSON 体积。

#### 兼容性影响

旧 JSON 缺少 `main_business` 时需要重新生成数据后才能完整展示。

#### 测试影响

验证接口权限、主营业务覆盖率、搜索、表头对齐和生产构建。

### 风险

- 主营业务文字较长，移动端需要横向滚动
- 个别公司可能缺少主营业务字段

### 验收标准

- [x] 页面只展示最新完整年度利润
- [x] 两年盈利筛选规则未改变
- [x] 页面展示主营业务并支持搜索
- [x] 主营业务接口可以批量访问

### 决定

接受。展示信息减少但筛选依据保持不变，新增主营业务能提高股票池可理解性。

### 实施记录

2026-08-23 完成数据字段、页面列和搜索逻辑修改。

## 示例，不是当前已确认变更

### CR-EXAMPLE：取消移动端固定股票列

- 状态：Draft
- 提出日期：2026-07-22
- 决定日期：
- 提出人：示例
- 关联原需求：UI-002
- 关联新需求：
- 关联决策：ADR-004

### 原需求

移动端表格通过固定左侧关键列提高名称、代码与排名的可读性。

### 新需求

取消移动端固定股票列，改为整个表格统一横向滚动。

### 修改原因

固定列可能占用过多横向空间，影响小屏幕设备上的可视宽度。

### 影响分析

#### 数据影响

无。该变更不改变指标公式、字段或数据源。

#### 前端影响

会改变移动端表格滚动体验、左侧层级和 sticky 行为。

#### 后端或脚本影响

无。Python 数据生成逻辑不受影响。

#### 部署影响

无直接部署影响。

#### 兼容性影响

旧数据兼容性不受影响，但用户习惯可能发生变化。

#### 测试影响

需要重新验证移动端布局、横向滚动、表头对齐和主要信息可读性。

### 风险

- 取消固定列后，横向滚动时股票身份识别变慢
- 移动端扫描效率下降

### 验收标准

- [ ] 小屏幕下可用宽度明显改善
- [ ] 取消固定列后仍能快速识别当前行股票

### 决定

示例，不代表当前项目已接受该变更。

### 实施记录

无。该条目仅用于说明记录方式。

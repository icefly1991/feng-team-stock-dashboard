# ST / 退市风险评分草案

日期：2026-10-06（用户时区）。研究与历史示范稿，尚未接入页面或发布。v0.2：重做问询主题分级和连续问询升级，替代v0.1的一律10分及笼统去重。

## 展示

新增一列“风险评分”：已核实风险分数 / 100、风险等级、最重要原因、核查完整性。点击展开各项加分、数值、报告期、披露日、原文链接和原文页码。未核查的项目单列，不计成零风险；核查不完整时只显示“已确认至少 X 分，核查未完成”，不显示绿色低风险。

分数是人工规则的风险强度，不是发生ST的概率。按当时已经公开的信息评分，未来公告不能计入历史分数。

## 必须保留的独立判断

1. 年报问询按正文事实分级，重复追问及不同独立问询均纳入，执行下述v0.2问询评分。提问涉及收入确认、商业实质、关联资金、回款或坏账计提时，逐项列出内容与链接，但不能把“要求解释”写成“已查实造假”。
2. 文章列出的严重红旗单独覆盖等级，显示“严重红旗”，保留实际加分明细，不伪造100分。信披/财务问题立案、财务审计无法表示或否定意见、内控否定意见、不能保证年报真实性、无法在法定期限披露等需要核对具体对象与正文。审计意见和ST/*ST法律后果分开。
3. 只对同一文件的转载、重复下载去重。二次/三次追问、确实延期、被监管指出未实质回复、新的独立问询均构成新的计分依据；普通回复不凭标题加分，也不凭已回复即清零。立案进展公告无新增事项时不重复加立案基础分，发现新违规或升级为处罚仍新增计分。财务门槛的两档互斥，非标准审计意见档位互斥。公司和实控人同案是否累计40+30，应在规则确认时明确，不能默默选择。
4. “营收略高于门槛”“应收异常”“正常延期与不能法定披露的区分”、问询解除与有效期，都不能只靠模糊关键词决定。先记录待核实，不擅自补上分数。
5. 现有非亏损100只名单保持；评分先提供预警、排序和原因查看，不自动换股。是否按风险隐藏或排除，需用户明确。

## v0.2：问询评分设计

### 用户新增的高风险最低等级

用户2026-10-06提出任何违法违规、证监会介入相关事项都应是高风险。本草案按保守筛选意图落实为“违法违规/监管执法优先”，最低等级不能被其他低分稀释。分数下限为试行工程规则，不是法定风险评级。

- 公司相关已公开确认的违法违规，或证监会/派出机构采取警示函、责令改正等正式监管措施：最低40分、较高风险。记录违法事项、对象、金额/影响、来源及处理状态。
- 公司或相关实控人因信披、财务等公司相关问题被正式立案：最低60分、严重风险，未有明确解除依据前保留。立案不等于已认定违法，但适用保守风险等级。
- 涉嫌重大违法强制退市、严重财务造假等明确监管风险提示：最低80分，并显示严重红旗。
- 对轻重不同的违规保留40/60/80等级区分；正式行政处罚、交易所纪律处分与普通问询不是同一种文书，分别识别。
- 正常发行/再融资审核、行政许可或一般程序性工作不因“证监会”字样而计执法高风险；普通问询不是违法认定，仍按主题与追问规则评分。已涉及实际监管措施或立案的问询链，适用更高最低等级。
- 同一事项总分取已有计分与对应下限的较高者，不能把“最低60分”再作为额外60分叠加。监管函要求解释涉嫌事项与正式认定结果分开标注。

以下为待回测的工程权重，不是交易所规定的分值或已校准的ST概率。0—19信息完整且没有重大预警，20—39关注，40—59较高，60—79严重，80—100极高；严重红旗独立覆盖等级。缺失覆盖始终另标。

### 1. 主题基础分，每个独立问询事项取最严重一档

| 问询内容与事实 | 基础分 |
|---|---:|
| 单纯格式、补充披露、一般业务说明，未列示重大异常 | 5 |
| 业绩变动、毛利/费用异常、并购估值或业绩承诺兑现 | 15 |
| 原文列出明显异常，追问收入确认、商业实质、回款、坏账、重大减值或资金缺口 | 25 |
| 原文列出资金去向不明、可能占用或未披露关联、交易真实性矛盾，或重大持续经营疑点 | 35 |

不能仅因出现“是否存在关联关系”“真实性”等常用措辞就套35分，必须记录与之对应的具体异常事实。重组/再融资/IPO程序性审核与上市后持续监管分开，不能仅按问询轮次视为同等风险。

### 2. 同一事项持续升级

| 新进展 | 加分 |
|---|---:|
| 监管正式二次追问同一未解决事项 | 15 |
| 第三轮及后续新增追问 | 每轮15，追问加分合计上限30 |
| 原文确认为延期回复 | 首次5；累计两次及以上10，延期项上限10 |
| 监管明确指出未按要求披露、前后矛盾、缺乏实质回复或必要证据 | 15（同类未解决状态只加一次，有新事实另列） |
| 同函另有独立重大主题 | 每增加一个主题5，上限10；同一收入确认问题的多种表述算一个主题 |

同一事项得分=min(60,主题基础分+追问升级+延期状态+明确回复异常+独立主题)。若主题因新事实升级，替换基础分，不把新旧基础分叠加。不能把回复文件、会计师意见、券商意见误算成三轮监管问询；轮次以监管新函/明确追问为准。

### 3. 不同事项分别计算并累计

收入确认问询与另一宗独立资金占用问询分别计算；同一事项换标题、换文号或补充回复不自动变成独立案件。问询模块分=min(80,各有效事项分之和)，再与财务、审计等模块合并，总分封顶100。

举例（虚构）：重大回款异常25分、第二轮追问15分、两次延期10分、监管指出遗漏关键证据15分，该事项原始65，按事项上限计60，已达严重风险，不必等立案。同一函三个网站转载仍是25；不同的收入问询25和独立资金去向问询35累计60。分数同时附每一项原文链接。

### 4. 状态及时间

- 默认回看最近24个月的问询和升级轨迹；超过24个月仍明确未解决的重大事项继续纳入，不因过期自动当作安全。历史检索不完整则标记覆盖缺失。
- 独立事项的开始时间、最新进展、已核实延期次数与追问轮次、已解决/未解决/未知分开存储。“未找到关闭函”不等于一直未解决，“公司说已回复”也不等于监管已认可。
- 降级要有可核对的更正、回款/归还、独立核查或监管处理依据；保留历史峰值和首次预警日期，不把历史删除。
- 财务异常如已在财务模块计分，不因其又被问询就再次加相同的财务分；问询行为和升级本身仍可计分。原文数值用于印证主题等级，不另外设置随意“共振分”。

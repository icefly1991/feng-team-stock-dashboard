# 牛散观察名单维护说明

对应 DATA-016 / UI-020，首版核对日为 2026-09-18。

名单位于 `config/investor-watchlist.json`，先按 DATA-017 从 16 位扩展为 50 位，再按 DATA-019 扩充为 100 位，当前版本 `2026-09-18.4`。保留原名单，增加专业持仓名录里的自然人观察对象。它不是官方名单、完整名录或投资能力排名，也不证明全部对象处在相同资金规模或收益等级。

本次新增 50 人的选取依据：2026-09-18 浏览器实际访问特特股“2026 牛散名单”中按持有股票数量排序的自然人名录（页面持仓统计期为 2026-06-30），按该名录顺序去除原 50 个姓名，补充前 50 个独立姓名。不是按短期股价涨幅、持仓收益或“最强牛散”排名选取，也不会随外部榜单变化自动换人。原 50 人顺序完全保留，新增对象追加在后。

100 人版重算结果：当前两页去重 170 股，查询错误为零；79 股共 124 条姓名匹配，相比同一股票池的 50 人版增加 10 只匹配股票。逐股原始快照与旧匹配保持一致，仅观察姓名覆盖范围扩大。名单总数和来源自动显示在两页共享组件中，无需修改前端硬编码。

每位新增对象使用 `teteguProfile...` 来源条目，链接指向其个人持仓页，而不是仅指向总名录。新增 50 个个人页均经浏览器验证返回 200、标题及正文对应姓名，使用可访问的 HTTP 地址；来源只证明名录中的同名记录，不构成本人身份认证。后续实际持股变化仍以 Tushare 的逐股披露快照计算。

每个姓名的 `sources` 指向媒体报道、公司公告或专业持仓名录，记录发布日期或动态页面检索核对日及链接。扩展对象来自特特股 2026 名录和热门列表的自然人条目，排除其中的机构、基金和产品；未使用短期涨幅榜，未将相关人士合并成家族。页面区分单纯名录收录与媒体报道依据。动态名录的检索结果包含较早持仓周期，因此仅用于候选姓名，不用于本项目最新持仓判断。

按 CR-008，章建平、葛卫东在前，原 16 人顺序保留，扩展对象随后展示；顺序不代表排名。页面介绍与搜索提示不突出特定个人。历史报道保留原日期。来源用于解释为何关注此姓名，不能证明某只股票的同名股东就是报道中的同一人；不把其他同名人物的职务、业绩或事件嫁接到该观察对象。

2026-09-18 实际浏览器逐一核对全部 11 个名单来源及 Tushare 说明页：特特股桌面 HTTPS 报证书域名错误、手机 HTTPS 报 TLS 协议错误，改为两个实际返回正常名录的 HTTP 地址。辰奕智能半年报改为新浪公告 HTML，证券时报历史专题改为电子报 HTML，避免 PDF 下载/预览差异。其余链接核对正常。`links_checked_at` 记录本次可访问性核对日期，不表示永久可用。未来维护时必须实际访问目标内容，不把搜索引擎缓存当成当前链接可访问的证据。

增删姓名时同步更新 `version`、`reviewed_at`、来源条目，再运行 `python scripts/generate_shareholder_watch.py`。Token 仅通过环境变量提供。名单及来源随生成结果发布，两页顶部可查看。

脚本对两页股票去重，从 Tushare `top10_floatholders` 查询近两年报告，排除生成日之后公告及报告期晚于公告日期的记录。取最新不同报告期及其上一期，各期仅使用最新公告快照，不把修订前后名单合并。输出每期完整返回名单、公告日期、股数、流通股占比，比例沿用接口百分比数值。

姓名仅做 Unicode NFKC 和空白规范化后精确匹配，不使用简称、模糊匹配、家族合并或产品穿透。

- 新进：本期存在，上期十名快照中不存在。
- 退出：上期存在，本期十名快照中不存在。
- 连续在列：两期都有同名股东。
- 变化未知：本期存在，但上期缺失或无法确认完整性。

未在名单不等于未持有；新进不等于首次买入，退出不等于清仓。数据代表报告期末持仓，非查询日实时持仓。返回股东不是十名（可能与并列排名、源数据处理等有关）时保守标记完整性待核，不以缺席推断变化。查询重试三次仍失败时明确发布不可用状态，不沿用旧信号充当本次结果。API 权限/更新时效依赖 Tushare。

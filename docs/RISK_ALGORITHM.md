# 股票风险预警算法 v0.1.1

初版基线：2026-10-06（v0.1.0）；2026-10-07修复版v0.1.1。关联 CR-022 / DATA-033 / UI-036 / ADR-017；继承用户确认的 CR-019 原始加分算法。本文说明实际代码行为，后续修改须同时更新规则版本、文档和验证案例。

## 1. 目标与输出

评分组件支持自选股、小市值双榜、创业板/科创板股票池。按用户最新要求，三个页面均展示风险评分列及覆盖说明，点击打开独立中文详情弹窗，历史测试页保留。不自动剔除股票，不改变市值、盈利筛选或行情指标。分数是规则风险强度，不是 ST/退市发生概率。

当前生成范围是三个页面股票的去重并集467只，包括小市值双榜两种模式；不是全A股扫描。原先9只格式预览、111只自选股阶段由CR-022的三页全量范围替代，算法版本仍为0.1.0。公告事件仍是核实样本，尚无完整公告采集服务。

每只输出分数、中文等级、四模块原始分（详细计算折叠）、普通触发项、组合加分、最低分、最高风险原因、最新风险日期、报告期/披露日、指标值、原始财报链接和待核查项。无财报不能生成的股票单独记录失败原因。公告不完整时，即使分数为0也显示“≥0 / 待核查”，不能解释为安全。

## 2. 最终公式与等级

```text
普通分 = 财务风险 + 财务质量 + 审计监管治理 + 生存流动性
组合分 = 所有已满足组合条件的加分之和
最低分 = 所有已触发最低分规则的最大值，无触发为0
最终分 = min(100, max(普通分 + 组合分, 最低分))
```

不加权、不归一化、不因良好指标减分。模块本身不封顶，最终总分封顶100。同一指标的嵌套档位只取一档；不同风险项允许累计。组合分另列，不重复计入四模块。示例：普通25+组合10得到35；普通35+组合15、最低70得到70；普通110+组合25得到100。

| 分数 | 中文等级 |
| --- | --- |
| 0—19 | 低风险；核查不完整时改为“待核查” |
| 20—39 | 需关注 |
| 40—59 | 高风险 |
| 60—74 | 严重风险 |
| 75—89 | 极高风险 |
| 90—100 | 应回避 |

边界按原始精度判断，最后分数保留两位小数。下表严格不等式处，恰好等于阈值不触发该档。

## 3. 核心指标、分值与数据口径

附件的18个核心指标通过数值字段和公告事件实现；现金/短债、利息保障为额外两个流动性字段。年度触发标记、已知亏损、零债务等是辅助判断，不另造加分项。

| 模块 | 条件 | 普通加分 / 处理 |
| --- | --- | --- |
| 财务 | 最新年度或近十二个月扣非净利润 < 0 | +8；年中使用近十二个月 |
| 财务 | 连续完整年度扣非亏损 | 2年+8；至少3年+12，取一档 |
| 财务 | 近十二个月营收 / 所属上市板块收入线 | <1.5倍+8；<1.2倍+15，取一档 |
| 财务 | 正式年度收入低于收入线，且利润总额、归母净利、扣非净利孰低 < 0 | +35；当前只自动处理正式年报，预告采集尚未接入 |
| 财务 | 归母净资产同比增幅 < -30% | +8；与上一年同报告期比较 |
| 财务 | 归母净资产 < 0 | 最低90，不另设普通分 |
| 财务 | 商誉 / 归母净资产 | >30% +5；>50% +10，取一档 |
| 质量 | 完整年度经营现金净流量连续为负 | 2年+5；至少3年+10，取一档 |
| 质量 | 三年累计经营现金净流量 / 三年累计归母净利 < 0.5 | +8；不是三个年度比率的平均数 |
| 质量 | 应收账款同比增速 - 同期累计营收同比增速 | >30个百分点+5；>50个百分点+10，取一档 |
| 质量 | 应收账款 / 近十二个月营收明显高于历史或同行 | +5；数值阈值待确认，自动计算比率，但不自动判异常 |
| 质量 | 其他应收款 / 归母净资产 | >10% +5；>20% +10，取一档 |
| 治理 | 年报问询 | 普通+5；严重+15，取一档；未分级标待核实 |
| 治理 | 二次年报问询 | +10，独立于首轮问询 |
| 治理 | 内控否定或无法表示意见 | +30，同时最低70 |
| 治理 | 证监会立案 | +35；财务/信披范围同时最低70 |
| 治理 | 资金占用 / 违规担保 | 各25—40分分档待确认；仅接受已核实且明确给定的分值，不能自行按25分填充 |
| 治理 | 财报否定或无法表示意见 | 最低90，不另设普通分；财报与内控意见分开 |
| 流动性 | 正式债务逾期 | +20 |
| 流动性 | 主要银行账户被冻结 | 最低80；不将任意账户冻结都归为主要账户 |
| 流动性 | 货币资金 / 短债 < 0.5 | +8；短债=短期借款+一年内到期非流动负债 |
| 流动性 | 近十二个月息税前利润 / 同期利息费用 < 1.5 | +5；不拿财务费用总额替代利息费用 |

### 收入线与正式年度触发

当前规则配置：主板3亿元，创业板/科创板1亿元，北交所5000万元。收入接近度是早期规则，使用近十二个月营收；+35正式年度规则不能用半年营收或近十二个月推算直接替代经审计年度条件。

依据：[沪市主板上市规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/mainipo/c/c_20260424_10816589.shtml)、[科创板上市规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/staripo/c/c_20260424_10816592.shtml)、[创业板上市规则发布通知](https://investor.szse.cn/lawrules/rule/allrules/bussiness/t20260424_620189.html)、[北交所2026年上市规则及衔接安排](https://dataclouds.cninfo.com.cn/sjother2/regulatory/2026/20260424/a8eb1135a3db4e26a210495e08d1d897.pdf)。配置的 `effective_from=20240101` 是本测试实现的查询起点，**不是声称规则于该日生效**；现有历史案例均在2025年，尚不支持任意旧年份法规回放。正式历史回测须建立逐板块逐财年法规版本表。

供应商缺少营收扣除后的收入。若原始年度营收已低于线且任一已知利润指标为负，可以触发+35；原始营收不低于线、但扣除后收入未知时不能认定排除触发。三项年度利润均已知且非负则该项为否。其他情况保留未知。当前不覆盖上市初期例外、交易类/规范类/重大违法类全部退市条款，也不输出法律意义上的确定 ST 判定。

### 数值与报告期

- 金额源单位为元；内部比率用小数，增速差用百分点。界面换算为亿元、百分比或倍数，不用展示四舍五入值判断阈值。
- 合并累计报表，使用实际披露日 `f_ann_date`，缺省才用 `ann_date`；报告期及披露日均不得晚于截止日。排除单季和母公司口径。
- 最新期取利润表、资产负债表、现金流表、指标表已披露期的并集最大值。某表最新期缺失，该表相关指标待核实，**不能整只股票回退旧报告期来填满数据**。
- 近十二个月流量=最新年内累计+上一完整年度-上年同期间累计；年末直接用年度。任何必要项缺失则比率未知，不混用旧期。
- 连续亏损/现金流从最新年报向前逐年检查，最多三年；不跳过缺失年度，遇到非负即终止连续计数。
- 三年现金转化分母≤0、同比基期≤0、权益分母≤0等不能解释的比率保持未知；负净资产另有最低90规则。
- 数据源明确给出短债或利息为0时标为无相应义务，不触发该比率项；空值不按0处理。
- 同期同披露版本重复指标行取字段更完整者；不跨新旧更正版本补空。供应商历史更正可能回填，按披露日期过滤仍不能完全还原当时信息集。

## 4. 最低分与组合

| 最低分条件 | 最低总分 |
| --- | --- |
| 财务/信披相关证监会立案 | 70 |
| 已核实重大资金占用，或占归母净资产 >10% | 75 |
| 内控否定/无法表示 | 70 |
| 财报否定/无法表示 | 90 |
| 归母净资产为负 | 90 |
| 主要银行账户被冻结 | 80 |
| 已确认财务造假 | 100 |
| 已决定终止上市、退市整理、已摘牌 | 100（v0.1.1新增） |

涉嫌、调查中不等于“已确认财务造假”。重大占用分档未知时仍可应用75最低分，不能因未确认25—40分档而漏掉硬标记。

| 组合 | 额外加分 |
| --- | --- |
| 严重年报问询 + 二次年报问询 | +10 |
| 严重年报问询 + 证监会立案 | +15 |
| 内控异常 + 资金占用 | +15 |
| 现金流较差 + 应收异常增长 | +10 |
| 亏损 + 营收接近收入线 | +15 |

现金流较差：连续至少两年经营现金净流量为负，或三年现金转化率<0.5。应收异常增长：应收增速高于同期营收超过30个百分点。亏损：近十二个月三项利润任一已知负值；其余利润缺失不能抵消已知亏损。接近收入线：近十二个月营收/收入线<1.5。内控异常包括保留、否定、无法表示，其中保留意见只参与组合，不自动获得30分或70最低分。

## 5. 公告记录、严重程度与去重

事件字段包括唯一 `id`、`kind`、`published_at`、标题、证据链接；按种类另需问询函号/严重程度、立案范围、审计意见、占用比例/重大标记、主要账户标记或明确分值。缺证据链接拒绝计分，未来披露及截止日前已解除的事件排除。同 `id` 仅计一次；同一函的多个下载、延期、回复不能当多个问询阶段。

年报问询按明确核实的普通/严重分类；当前**没有自动文本分级模型或已授权完整分级标准**，不能看见“问询”关键词就假定15分。多封不同函按函号识别二次，或明确录入 `second_inquiry`；仅有已核实二次记录、未取得首轮原文时仍可计二次10分。严重首轮15+二次10+组合10=35；不把重复问询全部当一次普通问询。更多轮次尚无额外分值，不自行递增。

财报/内控意见各取最新已披露意见；新标准意见替代旧异常意见。其他治理事件目前每种类别取最新未解除事件计一次，不按同类公告数量无限累加。没有自动时间衰减或过期，必须显式核实解除；不同年度问询的归组和多次独立立案累计方式是后续待改进项。

当前仅核实卓然等案例公告，普通财报审计来自供应商。财报审计不等于内控审计。人工核实公司原文可覆盖供应商意见。原文日期未确认时用核实的公开回复日，不能倒填首次发函日制造提前预警。

## 6. 缺失、依据与日期

未知保留 `null`，生成 `missing` 列表；没有事件记录不等于已扫描无事件。`complete=false` 时分数为已知风险下限，显示“≥”。即使100封顶仍保留缺失说明。三个未确认规则持续保留：应收历史/同行比较阈值、占用25—40分分档、担保25—40分分档。当前全部已评分股票公告覆盖状态均不完整。

普通财务触发项链接到本次五张原始表快照；公告触发项链接到披露原文。最高原因优先最高最低分，其次最高单项普通加分；组合独立列出。最新风险日期取有风险公告公开日与财务触发项实际披露日的最大值，连续年度项使用年报披露日；不是数据下载日，也不是股价首次下跌日。财报时间、风险截止时间和行情时间分别显示，互不冒充。

## 8. 案例、验证边界与下一版

已保留卓然2025-06-28、2025-08-30，海利2025-08-28三个早期截面，已知下限分别31、51、25。2025截面不得含2025-12立案或2026异常审计。案例是计算与时间过滤的回归样本，尚未证明能在股价大跌前稳定发出预警。

后续按顺序改进：完整公告覆盖和更新时效；问询严重度细分与人工复核规范；三项未明确阈值；各年度法规例外与营收扣除字段；不同年度问询归组和解决状态；历史原始信息集存档；时间序列回测与误报漏报评估；再讨论模块权重。

每次改算法：建立需求/CR → 保存旧版本规则和案例快照 → 明确字段、时点和边界 → 更新版本号与本文 → 跑阈值/组合/最低分/未来信息测试 → 比较同截止日旧新分数、触发原因和缺失率 → 在测试页人工审阅 → 再融入三页。只改显示无需改算法版本；分数、阈值、组合、缺失处理等影响结果的改动必须记录版本。未校准前不输出“退市概率”。

## 10. v0.1.1：交易资格与已知退市事实（CR-023）

终止上市已经确定时，不能再只按财务累加得出较低综合分。新增确定终止状态的最低100，普通财务项、组合及原最低分不变。股票交易资格与风险评分分别校验，剔除后仍保留回归/审计资料。

数据层：`generate_listing_status.py`抓证券基础信息L/P/D，保存`listing-status.json`及更新时间；`config/listing-risk-events.json`记录核实的终止上市决定、公开日期和证据。基础状态L不能覆盖已经公开的终止上市决定，因为退市整理期间仍可能列为L。普通ST/*ST不等同退市。

优先级：已公开且未晚于截面的核实决定→截止日前证券状态快照→股票简称退市标识。确定终止上市、退市整理或已退市都先从候选剔除，再按市值取250/100只，避免空名次；前端同时校验当前状态与决定表，旧JSON不能重新展示退市股。退市日期在未来不能当已经摘牌，核实决定公开之前的历史截面不得加上后来的100分。当前名称启发式不用于历史案例推断。

自动更新顺序新增：上市状态→股票池→三页风险。上市状态源失败时脚本抛错、保留上次快照，阻止生成链继续发布不一致结果。原始财务快照继续供审计；一般问询/立案等公告仍非完整扫描。

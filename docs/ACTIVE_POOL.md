## 平均波幅

`TR_t = max(high_t-low_t, abs(high_t-close_(t-1)), abs(low_t-close_(t-1)))`

`avg_range_60d_pct = mean(TR_t / close_(t-1) * 100，最近60个交易日)`。

先逐日标准化，再算术平均；包含跳空，前复权OHLC同口径，不是Wilder ATR(14)除以当前股价，不是收盘收益标准差，也不是60日累计涨幅。60日约三个月。至少61条连续有效行情，缺失不填零。120日同理。4%相比2%代表平均每日真实波幅两倍，而非收益两倍。

## 初版实施参数

沪深北正常上市普通A股，排除ST、退市整理；最近121个市场交易日行情完整且每日有成交。60日平均成交额至少0.5亿元、中位至少0.3亿元；60/120日平均波幅均至少2%。这些是可调整的工程初值，不是用户指定的数字。

合格行情候选中，60日波幅百分位占50%、120日占35%、60日绝对涨跌至少3%的频次百分位占10%、小市值百分位占5%。分数从高到低核验财务，取前100只合格股票，不降低盈利标准补足数量。分数只用于选池，不代表投资价值。

财务以截至生成日已披露正式合并累计报表为准。最新完整年报为锚点，连续三年归母净利润和扣非净利润均正，最新TTM归母和扣非净利润均正。TTM=本期累计+上年度全年-上年同期；最新期为年报则直接取全年。不跳过最新亏损/缺失报表。缺失资料单独记录，不能当作通过。五年归母盈利另行标注，不是硬性门槛。现金流、资产负债率及利润同比作辅助风险提示，银行/保险/证券等金融企业单独标示，不套用普通企业现金流或负债比率判断。
